# SFX Credits

Sound effects in this directory come from the HyperFrames `media-use` bundled library, sourced from [Pixabay](https://pixabay.com/sound-effects/) and used under the [Pixabay Content License](https://pixabay.com/service/license-summary/): free for commercial and non-commercial use, modification allowed, no attribution required.

| File | Use |
| --- | --- |
| `click.mp3` | cursor click, tab switch, button press |
| `pop.mp3` | cards or images popping in |
| `whoosh-short.mp3` | compare wipe, scene push |
| `chime.mp3` | CTA landing |

More effects (riser, sparkle, typing, notification…) are available through `/media-use`.
