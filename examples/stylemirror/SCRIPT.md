# SCRIPT.md — StyleMirror AI 推广视频脚本

> 面向:制作与审核本视频的人。画面屏显文案为英文(出海),说明为中文。
> 依据:线上 stylemirrorai.com 首页(2026-10-23 抓取)与本地源码核对。

## 1. 定位

| 项 | 内容 |
| --- | --- |
| 产品 | StyleMirror AI,AI 发型更换工具:上传自拍,换发型、发色,脸不变 |
| 目标用户 | 想换发型但怕剪坏的人;带沙龙/杂志/明星参考图的人 |
| 一句话信息 | 剪之前先看见自己,换发型,不换脸 |
| 情绪弧线 | 犹豫 → 轻松上手 → 惊喜揭晓 → 想自己试 |
| 行动号召 | 打开 stylemirrorai.com,注册领 20 免费积分 |

## 2. 制作形式

- 无旁白,靠屏显大字幕 + 音乐 + 点击音效。
- 横屏主版 30 秒(1920×1080 / 30fps),竖屏版 24 秒(1080×1920 / 30fps)。
- 音乐:明亮、轻快、有清晰节拍,便于快闪镜头卡点。**音乐来源待定**(见 TASKS.md 待确认项)。

## 3. 核心卖点(按出镜顺序)

1. **换发型不换脸**:脸、妆容、背景保持不变。(镜头 4 的主结论)
2. **三种方式**:选 65 款预设 / 上传参考图 / 文字描述。(镜头 3)
3. **上手简单**:上传自拍即可开始,数秒出结果。(镜头 2)
4. **不止发型**:免费的脸型检测、肤色分析等工具。(镜头 5,仅快闪)
5. **试用门槛低**:注册送 20 积分,无需信用卡。(镜头 6)

## 5. 禁止出现

- 发色页、眼镜试戴、Hair Filters、`/filter/*`:**线上未上线**,不得出现在任何画面或文案中。(首页色板里已有的发色名可作为 Studio 的一部分出现,不单独宣传"发色功能页"。)
- "免费无限" / "free forever" / "no sign-up":免费下载带水印,未登录点生成会弹注册框。
- 虚构的生成中画面、进度条数字、用户评价、使用量数据。
- 把 3 组示例说成"所有结果"。
- 页脚第三方 "featured on" 徽章。

## 7. 音效建议

- 点击:轻柔 UI 点击。
- 滑块揭晓:短促 whoosh,落点与 after 图出现对齐。
- 快闪:每个切换卡一个节拍。
- CTA:单个上扬提示音收尾。
- 总音量留给音乐的动态,字幕不依赖声音即可读懂(社媒常静音播放)。
