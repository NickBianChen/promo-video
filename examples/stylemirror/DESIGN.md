# DESIGN.md — 视觉规范

> 来源:线上站点与本地 `globals.css` 的营销主题(紫色体系)。源码 README 与旧 DESIGN.md 中的黑金/黄色海报风已被覆盖,**不要使用**。

## 1. 色彩

| Token | 值 | 用途 |
| --- | --- | --- |
| `--brand` | `#7d2ae8` | 主色:强调词、按钮、选中态、CTA |
| `--brand-strong` | `#5b1fb0` | 链接、深色强调 |
| `--brand-soft` | `#f1eafe` | 浅紫底、高亮块 |
| `--brand-line` | `#d9c6fb` | 浅紫描边 |
| `--ink` | `#0e1318` | 标题与正文 |
| `--muted-ink` | `#4a5560` | 次要文字 |
| `--border` | `#e3e6ea` | 卡片描边 |
| `--canvas` | `#ffffff` | 画布底色 |
| `--credit` | `#15803d` | 仅用于积分相关小标 |

规则:
- 画面以白底为主,紫色只用于强调,单屏紫色面积不超过 30%。
- 背景只在白 → `#f1eafe` 的柔和渐变内变化,不使用黑底、黄底。
- 文字对比度 ≥ 4.5:1(`npx hyperframes check` 会检测)。

## 2. 字体

| 角色 | 字体 | 字重 | 用途 |
| --- | --- | --- | --- |
| 标题/正文 | Plus Jakarta Sans | 800 / 600 / 500 | 大字幕、正文 |
| 数字/标签 | Martian Mono | 500 | 积分数、"65"、小标签 |

- 字体文件在 `assets/fonts/`,必须用 `@font-face` 引入(非内置字体不会按名称解析)。
- 大标题字距收紧(约 -0.03em),行高 1.05。
- 字号(横屏 1920×1080):主标题 120–140px;副标题 56–64px;标签 28–32px;小字声明 24px 以上。
- 竖屏(1080×1920):主标题 100–116px,每行不超过 12 个字符,最多 3 行。

## 3. 布局与安全区

- 内容在 90% 动作安全框内,字幕和关键文字在 80% 标题安全框内。(Studio 自带参考线,不手画。)
- 竖屏另加:顶部与底部各 15%(约 288px)留空,避开社媒界面遮挡;字幕与 CTA 只放中间区域。

## 4. 卡片与 UI 呈现

- 真实 UI 截图放入圆角卡片:圆角 24px,1px `--border` 描边。
- 阴影柔和且单向向下:`0 24px 60px rgba(14,19,24,0.12)`,不使用硬偏移阴影。
- UI 截图只做缩放、裁切、平移、轻微 3D 倾斜(≤ 6°),**不改变其内容、文案和颜色**。
- 按钮为全圆角胶囊,紫底白字;标签芯片为浅灰底圆角。
- 对比图使用站点原版样式:左上 `Before` 深色胶囊,右上 `After · …` 白色胶囊,中间白色圆形把手。

## 5. 背景与装饰

- 浅紫柔光(2–3 个大半径径向渐变,缓慢漂移)。
- 可选极淡颗粒层(不超过 4% 不透明度),通过 HyperFrames 的 grain 组件实现,不使用 CSS filter。
- 装饰元素只有:星形火花(取自 logo 的八角星)、光标、点击涟漪。不添加与产品无关的插画。

## 6. 动画节奏

- 时间线:GSAP,所有动画是时间的函数,不用 `Date.now()`、随机数、`repeat:-1`。
- 缓动:入场 `power3.out` / `expo.out`;出场 `power2.in`;滑块扫动 `power2.inOut`。
- 节奏:入场 12–18 帧;停留至少 18 帧可读时间(大字幕每词不少于 4 帧);镜头内元素错峰 3–5 帧。
- 文字入场:自下而上逐词出现,轻微模糊到清晰。
- 光标:用 registry 的 `agent-cursor` 候选;移动用曲线路径,到达后 6 帧内触发点击涟漪。
- 快闪镜头:每个画面 30–36 帧,切换点对齐音乐节拍(`npx hyperframes beats --json`)。

## 7. 转场

- 镜头之间统一用:**推近 + 交叉淡化**(8–10 帧)或**紫色柔光擦除**(10 帧)。
- 同一支视频最多使用两种转场,避免风格割裂。
- 揭晓段使用滑块擦除本身作为转场。
- 转场优先在 registry 中搜索(例如 `before-after-wipe`),再决定是否自写。

## 8. 横竖屏一致性

- 两个版本共用色彩、字体、卡片、转场与音乐。
- 竖屏不是裁切横屏:UI 取竖向局部放大,对比图占满宽度,文案更短。
- 共享素材与组件放在 `compositions/` 里,通过变量切换文案与尺寸。
