# DESIGN.md — 视觉规范

> 来源:线上站点与本地 <globals.css / tailwind 配置>。品牌色写进 `assets/css/brand.css`;
> 画面风格由主题 `assets/css/theme.css` 决定(当前:<主题名>,见 `promo-video.json`)。

## 1. 品牌色(brand.css)

| Token | 值 | 来源 | 用途 |
| --- | --- | --- | --- |
| `--brand` | | | 强调词、按钮、CTA |
| `--brand-strong` | | | 深色强调、链接 |
| `--brand-soft` | | | 浅色底、徽章底 |
| `--brand-line` | | | 浅色描边 |

规则:
- 强调色单屏面积不超过 30%。
- 文字对比度 ≥ 4.5:1(`check` 会检测)。

## 2. 字体

| 角色 | 字体 | 字重 | 用途 |
| --- | --- | --- | --- |
| 标题/正文 | <默认 Plus Jakarta Sans,可换站点字体> | 800 / 600 / 500 | |
| 数字/标签 | <默认 Martian Mono> | 500 | |

- 非内置字体必须用 `@font-face` 引入,文件放 `assets/fonts/`,在 theme.css 里声明。
- 字号(横屏):主标题 120–140px;副标题 56–64px;标签 28–32px;小字 ≥ 24px。
- 竖屏:主标题 100–116px,每行 ≤ 12 个字符,最多 3 行。

## 3. 布局与安全区

- 内容在 90% 动作安全框内,字幕与关键文字在 80% 标题安全框内。
- 竖屏:顶部与底部各 15%(288px)不放文字。

## 4. UI 呈现

- 真实截图放进 `.ui-card`,只做缩放、裁切、平移、≤ 6° 倾斜,**不改内容、文案和颜色**。
- 对比图沿用站点原版的角标文案。

## 5. 动画与转场

- 缓动和节奏来自主题(`pv.ease()` / `pv.d()`),场景里不写死。
- 转场:推近 + 交叉淡化(相邻宿主重叠 0.2s);一支片最多两种转场。
- 镜头切点对齐音乐节拍。
